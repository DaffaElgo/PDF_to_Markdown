# PDF_to_Markdown
Convert research-paper PDFs into Markdown, images, and LaTeX equations using Marker (Kaggle / Colab, GPU or CPU).

`Syntax Convertion.ipynb` (v5): per-PDF mode selection (text layer vs OCR), all-GPU parallel batches, result caching, `DEVICE` = auto | cuda | cpu. Parameters are at the top of cell 2.
